# 小爱家庭库存 · XiaoAI Pantry

给食品和日用品按批次记数量、存放位置、到期日或查看日。网页可独立运行，也可以用原厂小爱音箱录入中文。厨房持续有人时，音箱会合并播报全家各处需要处理的物品。

## 五分钟试用

安装 Python 3.11 或更高版本，在仓库根目录运行：

```sh
python app.py
```

打开 http://127.0.0.1:8768 ，使用首次启动生成的 `data/web.token` 登录。应用及测试只依赖 Python 标准库。默认只监听本机，不连接小米。运行 `python -m unittest -v` 可用临时库存验证业务规则。

## 用 Docker 部署

```sh
docker compose up -d --build
docker compose exec pantry cat /data/web.token
```

第二条命令在你自己的终端显示家庭访问码。浏览器同样访问 http://127.0.0.1:8768 。若要让家人通过 Wi-Fi 访问，将 [.env.example](.env.example) 复制为 `.env`，把 `PANTRY_BIND_IP` 设为部署主机的局域网地址，再执行同一启动命令。当前服务使用家庭共享访问码和 HTTP，面向可信家庭网络。

Compose 将库存和每日备份写入两个持久卷。默认两个卷位于同一宿主；如需防磁盘故障，把备份目录映射到另一块磁盘，并让容器用户（UID 10001）可写。CSV 方便查看和迁移当前库存，完整恢复仍用 SQLite 备份。

## 日常操作

| 想做什么 | 直接输入或在唤醒小爱后说 |
| --- | --- |
| 买入并记录位置 | 买了两包饼干，放在橱柜，周五到期 |
| 只记数量 | 买了三卷纸巾，只记库存 |
| 到日子看看 | 菠菜，周日提醒我看看 |
| 消耗 | 橱柜里的饼干吃了一包 |
| 查全家、查单处、找东西 | 家里有什么快到期了？／橱柜里有什么？／牙膏放在哪？ |

没说位置的批次标为「未指定」。网页可以改期、移动整批、扣减、按位置筛选，或导出全部在库批次的 CSV。点「查看待处理库存」可集中处理已过期、今天到期、临期和待查看的批次。用掉与丢弃分开记，查看日到了可点「明天再看」。这些操作可在最近 20 次变更中核对并撤销最近一笔。也可以直接说「橱柜里的饼干扔了一包」。

首次语音入库回「已记录」，已有同名库存时播报原有数量和日期。先写库存再确认，因此不要用音箱自己的保存建议判断是否入库。

## 选配小爱与厨房提醒

目前适配原厂 OH2P 和米家人在传感器 `xiaomi.sensor_occupy.03`。需要已登录的 XiaoMusic 服务，家庭网页可单独使用。按 [.env.example](.env.example) 填写容器可访问的 URL、目标音箱的 MIoT DID、宿主上的 XiaoMusic 登录文件绝对路径。容器 UID 10001 需要对该文件有读取权限；只给所需账户读权限。需要主动提醒时再填写传感器 DID。

```sh
docker compose -f compose.yaml -f compose.xiaomi.yaml up -d --build
```

语音来自小米云对话记录。若官方 App 没有当次记录，服务也可能收不到。原厂小爱可能先给自己的回答，随后才是库存回执。厨房传感器决定播报时机；所有位置的库存都纳入提醒。默认 09:00–20:00、到期前两天、每天最多主动播报一次。可在网页调整，时区为上海。
